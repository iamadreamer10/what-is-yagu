## 1. Context (배경, 외부 제약, 기존 패턴)

**배경**
- 스터디 사이드 프로젝트. 개인으로 진행하고, 주 1회 스터디원 앞에서 진행 상황과 트러블슈팅 1건을 발표한다.
- 목표 우선순위
  1. AI를 최대로 활용하는 개발을 위해 기획/설계를 새로운 방식(SDD)으로 준비해 본다.
  2. 서비스에 AI 기능을 넣어 본다. (컨셉이나 CRUD 위주 프로젝트는 이미 여러 번 해봤다.)
  3. 같은 조건이면 금융 도메인으로 한다. (필수 아님. 이번 주제는 금융이 아니며, 금융 기능은 확장판에서 생각한다.)

**문제 정의**
- 최근 한국야구의 인기가 높아지면서 입문자가 빠르게 늘고 있다. (근거: KBO 연도별 관중 수 추이. 수치와 출처는 1주차에 기입)
- 입문 콘텐츠는 많지만 목차형이라, 용어를 모르는 뉴비는 원하는 항목을 고를 수 없다. 궁금한 걸 들으려면 콘텐츠가 다뤄 주길 기다리거나 옆 사람에게 물어야 한다.
- 지인을 통해 배우면 그 사람의 응원팀 정보에 치우친다.
- 뉴비의 질문은 용어가 아니라 묘사다. 예: "힘없는 땅볼인데 왜 환호해?", "0.3? 그게 뭔데?" (`docs/eval/newbie-questions.md`)

**고객 (초안)**
- 가족, 친구, 애인을 따라 야구를 접했고 앞으로 볼 생각이 있는 야알못 뉴비.
- 직관이나 중계 중 눈앞의 장면이 궁금하지만, 용어를 몰라 검색할 수 없고 매번 옆 사람에게 묻기는 눈치가 보인다.

**목적 (초안)**
- 눈앞의 장면을 자기 말로 물으면 바로 이해시켜 주는 "옆자리 야구 친구".

**외부 제약**
- 기간: 총 6주 (2주 기획/설계 + 4주 개발), 최소 기능(MVP)만 만든다.
- 개발 도구: Claude Code (Pro 요금제, 5시간·주간 사용 한도가 있고 채팅과 공유).
- 서비스 안에서 호출하는 AI API는 Pro 구독과 별도로 크레딧이 필요하다.
- 실시간 경기 데이터는 없다. 장면은 사용자의 묘사로 받는다.

**기존 서비스 (레퍼런스)**
- 야구나라 (yagoonara.com/guide/rules): 야알못 대상 규칙 64가지를 쉬운 말·영상·도식으로 정리. 목차형이며 질문 창구는 댓글. 구조만 참고하고 글은 복사하지 않는다.

## 2. Scope

**할 것 (MVP)**
- 입문 가이드: 경기 중 막히는 장면·용어를 상황형으로 질문하면, 근거 문서를 바탕으로 쉬운 말로 설명한다.
- 근거가 없는 질문에는 모른다고 답하거나 되묻는다.
- 응원팀 정하기: 뉴비가 재미로 해 보는 참고용 콘텐츠. 메인 기능이 아니며 정답을 주장하지 않는다. 일정이 밀리면 뺀다.

**하지 않을 것**
- 외부 크롤링에 의존하는 기능
- 실시간 경기 데이터 연동
- 판타지리그, 로스터 보강 추천

**확장판 (MVP 이후)**
- 스토브리그: 핫한 선수, FA 제도 해설
- 금융 기능: 같은 설계를 금융 문서에 옮겨 보는 실험
- KBO 선수 비교

## 4. Verification (무엇을 어떻게 검증할지)

- 설계 방식의 효과: 같은 작은 기능을 명세와 평가 기준을 준비했을 때와 안 했을 때 만들어, AI 결과물이 의도와 얼마나 일치하는지 비교한다.
- 설명의 정확성: 평가 질문 세트로 AI 설명을 직접 검수한다.
- 근거 준수: 근거 문서 밖의 질문에 모른다고 답하는지 확인한다.
- 사용 후 체감: 야구를 잘 모르는 스터디원이 써 보고 막힌 지점을 말한다. (정성 피드백, 개선 입력으로 사용)
- 측정하지 않는 것: 입문까지 걸린 시간, 응원팀을 정하기까지의 기간. 응원팀 정하기는 평가 대상에서 뺀다.

## 5. Prerequisites (실행 전제)

- Claude Code는 Pro 계정으로 로그인한다. `ANTHROPIC_API_KEY` 환경 변수가 있으면 API 요금으로 나가므로 주의한다.
- 서비스용 AI API 크레딧과 비용 확인 (1주차)
- 기술스택: 백엔드 Spring, 프론트엔드 React + Vite, DB PostgreSQL + pgvector, 인프라 AWS EC2 1대 + Docker Compose, CI/CD GitHub Actions, Java 21, Spring Boot는 Spring AI와 호환되는 최신 안정 버전 (D-009, D-017~D-022).
- AWS는 신규 가입 무료 플랜 크레딧(100달러) 안에서 운영한다. 결제 알림(Budget)을 먼저 설정한다. (D-020)
- LLM 제공사, 임베딩 방식처럼 기능에 따라 달라지는 기술은 1주차에 가정하고, 각 기능 구현 전에 그 기능에 필요한 만큼 확정한다. (D-014, D-015, D-016)

## 6. Glossary (용어)

- **야알못 / 뉴비**: 야구를 잘 모르는 입문자
- **SDD**: 스펙 주도 개발. 코딩 전에 명세를 쓰고, 그것을 사람과 AI의 공통 기준으로 삼는 방식
- **근거 문서**: AI가 설명할 때 기대는, 내가 직접 쓴 입문 지식 문서
- **RAG**: 질문과 관련된 근거 문서를 찾아 AI에게 함께 넘겨 답하게 하는 방식
- **평가 질문 세트**: 뉴비의 실제 질문과 기대 답변 기준. 개발 전에 만든다
- **MVP**: 최소 기능 제품
