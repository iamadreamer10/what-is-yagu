# 설문 초안 (야구 뉴비)

> 상태: 초안 (2026-11-16). 문항을 일단 모두 넣었다. 길이는 확정 전에 줄인다.
> 대상·기준·경로: D-043. 알아낼 것(R1~R5)에서 출발하고, "이런 기능이 있으면 쓰겠냐"는 묻지 않는다 (D-038).
> 도구: 구글 설문. A1 답에 따라 B(본 사람) / C(아직 안 본 사람)로 나뉜다.

## 알아낼 것

| # | 알아낼 것 | 쓰이는 곳 | 문항 |
| --- | --- | --- | --- |
| R1 | 뉴비는 어디서 막히는가 | 정보 묶음의 범위와 순서 (D-037) | B3, C3 |
| R2 | 막혔을 때 어떤 말로 묻는가 | 뉴비의 언어 (D-041), 평가 질문 세트 | 설문에서 받지 않는다. 대놓고 물으면 꾸밈없는 표현이 나오지 않는다. 함께 볼 때 나온 말을 그대로 기록한다 (`docs/eval/newbie-questions.md` 방식) |
| R3 | 지금은 어떻게 알아보고, 무엇이 아쉬운가 | 차별점 | A3, B4 |
| R4 | 계속 보게 만든 것, 마음이 식은 순간 | 지속성 (D-036) | B5, B6 |
| R5 | 관심자는 왜 아직 보지 않았는가 | 넓힌 고객 (D-042) | C1, C2 |

## 도입문

야구를 잘 모르는 분들이 어디서 막히는지 알고 싶어 만든 설문입니다. 5분 정도 걸리고, 이름이나 연락처는 받지 않습니다. 정답은 없으니 떠오르는 대로 답해 주세요.

## A. 공통

**A1. 야구 경기를 본 적이 있나요?** (하나만)
- 야구장에서 직접 본 적 있다
- TV·온라인 중계로만 봤다
- 둘 다 해 봤다
- 아직 본 적 없다

**A1-1. 앞으로 야구를 더 알아 가고 싶은 마음이 있나요?** (하나만)
- 있다 → A2로
- 잘 모르겠다 → A2로
- 없다 → 감사 인사 후 종료
- (메모: 고객은 "앞으로 야구를 즐기고 싶은 사람"이라(D-042) 관심 없는 사람의 의견은 받지 않는다. "잘 모르겠다"는 관심이 생기기 전 단계로 보고 계속 받는다.)

**A2. 야구를 얼마나 안다고 느끼나요?** (하나만)
- 1 거의 모른다 (규칙도 잘 모른다)
- 2 기본 규칙만 조금 안다
- 3 경기 흐름은 대충 따라간다
- 4 기록이나 작전도 어느 정도 안다
- 5 잘 안다
- (메모: 4~5는 D-043의 "스스로 잘 모른다고 느끼는 사람" 기준 밖이다. 설문을 끝낼지, 받고 따로 볼지 정한다.)

**A3. 야구에 대해 알아볼 때 주로 어떻게 하나요?** (여러 개 선택)
- 경기를 직접 보면서 익힌다
- 검색해서 찾아본다 (포털, 나무위키 등)
- 유튜브 같은 영상으로 본다 (입문 영상, 하이라이트 등)
- ChatGPT 같은 AI에게 묻는다
- 야구를 잘 아는 친구·가족에게 묻는다
- 야구 커뮤니티에 묻거나 글을 읽는다
- 따로 알아보지 않는다 / 아직 알아본 적 없다
- 기타 (직접 입력)

A1에서 "아직 본 적 없다"를 고른 사람은 C로, 나머지는 B로 간다.

## B. 본 사람

**B1. 야구를 처음 본 지 얼마나 됐나요?** (하나만)
- 올해 처음 봤다
- 1~2년 됐다
- 3년 이상 됐다

**B2. 처음에는 누구와 봤나요?** (하나만)
- 가족
- 친구
- 애인
- 회사·모임 사람들
- 혼자
- 기타 (직접 입력)

**B3. 주로 어떤 쪽에서 막혔나요?** (여러 개 선택)
- 경기 규칙 (아웃, 진루, 파울 등)
- 야구 용어 (병살, 볼넷, 희생번트 등)
- 숫자·기록 (전광판의 타율, 방어율 등)
- 경기 흐름 (몇 회까지 하는지, 왜 투수를 바꾸는지 등)
- 팀·선수 (누가 잘하는지, 지금 순위 등)
- 응원 문화 (응원가, 응원석, 홈·원정 등)
- 기타 (직접 입력)

**B4. A3에서 고른 방법으로 알아볼 때 아쉬웠던 점이 있나요?** (여러 개 선택)
- 설명에 또 모르는 용어가 나왔다
- 뭐라고 검색해야 할지 몰랐다
- 설명이 너무 길거나 많았다
- 맞는 정보인지 알 수 없었다
- 물어보기가 미안하거나 귀찮았다
- 특정 팀 이야기로 치우쳤다
- 특별히 없었다
- 기타 (직접 입력)

**B5. 야구를 계속 보고 싶게 만든 것이 있나요?** (여러 개 선택)
- 응원 분위기
- 마음에 드는 팀이나 선수가 생겼다
- 같이 보는 사람
- 경기를 이해하게 되면서 재미있어졌다
- 먹거리·나들이 같은 야구장 경험
- 특별히 없다
- 기타 (직접 입력)

**B6. 보다가 마음이 식었던 순간이 있나요?** (여러 개 선택)
- 무슨 상황인지 몰라서
- 경기가 너무 길어서
- 같이 볼 사람이 없어서
- 응원할 팀이 없어서
- 표를 구하기 어려워서
- 특별히 없다
- 기타 (직접 입력)

## C. 아직 안 본 사람

**C1. 야구에 관심이 생긴 계기는 무엇인가요?** (여러 개 선택)
- 주변 사람이 야구를 봐서
- 뉴스·SNS에서 야구가 인기라는 걸 봐서
- 응원이나 야구장 분위기 영상을 봐서
- 관심 가는 선수가 있어서
- 국제대회(WBC 등)를 봐서
- 기타 (직접 입력)

**C2. 아직 보지 않은 이유는 무엇인가요?** (여러 개 선택)
- 규칙을 몰라 재미없을 것 같아서
- 같이 볼 사람이 없어서
- 어느 팀을 응원해야 할지 몰라서
- 경기가 길 것 같아서
- 표를 구하기 어려워서
- 시간이 안 맞아서
- 기타 (직접 입력)

**C3. 보러 간다면 미리 알고 싶은 것은 무엇인가요?** (여러 개 선택)
- 경기 규칙
- 야구 용어
- 숫자·기록 읽는 법
- 경기 흐름 (몇 회까지, 얼마나 걸리는지 등)
- 팀·선수
- 응원 문화
- 직관 준비 (예매, 좌석, 준비물 등)
- 기타 (직접 입력)

## 마무리 (공통)

**D1. 야구에 대해 더 하고 싶은 말이 있다면 자유롭게 적어 주세요.** (서술, 선택)

## 정할 것

- 길이: 본 사람 11문항, 안 본 사람 8문항. (B 몇 경기는 B1과 겹쳐서, "이게 뭐지?" 서술형은 귀찮고 갑자기 떠올리기 어려우며 A2·B3과 겹쳐서 뺐다.) 5분을 넘을 수 있어 줄일 문항을 고른다.
- A2에서 4~5를 고른 사람 처리
- 응답 마감일과 11-18 보고 일정 맞추기
