## 1. 이번 주 산출물

- [x] 프로젝트 개요: 야구 입문자가 즐길 만큼 이해를 쌓도록 돕는 서비스
- [x] MVP 기능 3개: 야구 정보 / 재미로 정해 보는 응원팀 / 상황 검색
- [ ] ERD, API 명세, 아키텍처 그림: 후보만 정리, 다음 주에 완성
- 뉴비 설문 35명 응답 (뉴비 17, 야구를 잘 아는 사람 15, 관심 없음 3)

**설문 결과**
- 뉴비
  - 막힌 곳: 숫자·기록, 팀·선수, 응원 문화
  - 알아보는 방법: 친구·가족에게 묻기, 검색
  - 계속 보게 만든 것: 응원 분위기, 같이 보는 사람
  - 마음이 식은 이유: 경기가 길어서, 응원할 팀이 없어서
- 고인물
  - 입문할 때 막힌 곳: 경기 규칙, 팀·선수
  - 입문자가 먼저 알면 좋은 것: 경기 규칙, 용어, 팀·선수
  - 계속 보게 만든 것: 마음에 드는 팀·선수

## 2. 결정한 것과 이유

- **서비스 방향:** 야구 입문자가 알아야 할 정보(규칙, 기록, 팀·선수)를 묶어 보여 주는 서비스
- **기능 3개**
  1. 야구 정보: 기본 규칙과 용어, KBO 리그가 돌아가는 방식, 기록 읽는 법, 팀·선수 정보를 뉴비 눈높이로 보여 준다.
  2. 재미로 정해 보는 응원팀: 질문 몇 개에 답하면 나와 맞는 팀을 재미로 알려 준다.
  3. 상황 검색: 이해 못 한 장면을 자기 말로 적으면 관련 설명을 찾아 보여 준다.
- **AI 사용:** 질문을 알아듣는 데만 쓰고, 설명은 내가 쓴 문서에서만 가져온다. 지어낸 답을 막기 위해
- **데이터:** 크롤링 없이 직접 정리. KBO 사이트가 자동 수집을 금지하고, 개발 기간이 비시즌이라 기록이 바뀌지 않음
- **기술스택:** Spring Boot, React, PostgreSQL(벡터 검색 포함), AWS 서버 1대. 익숙하고 무료 크레딧 안에서 운영 가능
